Tips & shortcuts
Tools
Select S · Marker Q · Rect R · Circle C · Arrow A · Line D
Select
Click, or drag a box in empty space — left→right encloses, right→left touches. Shift/Ctrl‑click adds to the selection.
Transform
Drag to move, handles to resize. Drag +Shift duplicates, +Ctrl locks 45°. Resize +Shift keeps aspect, +Ctrl from centre. Arrow keys nudge (Shift big, Alt small).
New rect / circle
Hold Shift for a 1:1 square / perfect circle, Ctrl to draw from the centre — combine them.
Markers
Numbered 1, 2, 3 or lettered a, b, c — set Marker style, or press Tab in Marker mode to switch; Uppercase flips the letter case. Snap to shapes when Snap is on (hold Tab while dragging to flip). Scroll a selected marker to change it.
Lines & arrows
Ends snap to shapes and each other. Dragging an end: Shift = 45° steps (+Ctrl locks that step), Ctrl alone locks to the line's current axis, Alt disables snapping.
Edit
Delete/X remove · Ctrl+Z undo · Ctrl+Y redo · right‑click for a menu.
Crop
Crop opens a zoomable view to trim the image; the pixels are removed and it's undoable.
View zoom
Ctrl + scroll (or the zoom menu) zooms the canvas; Shift + scroll pans sideways. View only — the export is unchanged.

Copy snippet keeps the screenshot as a separate file with the annotations overlaid — inline only (GLightbox can't draw the overlay in its zoom). Download SVG bakes the screenshot + annotations into one file you reference as a normal image (![alt](images/name.svg)); it shows annotations inline and when zoomed with GLightbox. Annotation size scales with the image width, so marks render at the same on‑screen size across screenshots — the wiki fits every wide image to the text width — so set it once; Marker size tweaks markers on top. Drop a downloaded SVG back in to keep editing its annotations (sizes are restored exactly).
