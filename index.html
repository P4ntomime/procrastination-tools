procrastination-tools

Two small browser tools, each one the result of procrastinating on the work it was built to help with.

Annotate

Mark up a screenshot with numbered callouts, boxes and arrows. Exports a vector overlay you can edit again later.

annotate.html
Gantt A4

Write a plan as plain text, get a Gantt chart that prints on one A4 sheet. Drag the bars if you would rather not type.

gantt-a4.html

One HTML file each, no install and no account. Nothing you load or type leaves your browser, because neither tool makes a network request of any kind. The code was written by an AI assistant, not by me.

How that works, and what to watch out for

Your work is kept in this browser's local storage, so a private window, a cleared cache or a different machine all start empty. Export anything you want to keep: Download SVG in Annotate, Save .gantt in Gantt A4.

Save the page from your browser, or download the file from the repository, and it runs the same from your own disk with no network at all.

Both tools have only been tested in Chromium on Linux. They are untested in Firefox, Safari and on phones, and Gantt A4 can only link a file on disk in Chromium. The README lists the rough edges I know about, including an unreliable undo in Gantt A4.

To be clear about how these were made: I did not write the code. I described what each tool should do, used the versions I got back, said what was wrong, and repeated that until they were useful. The code itself is the AI's work. It comes with no warranty, from either of us. Each tool is a single unminified file, so reading the source before you trust it with something that matters is a realistic thing to do.
